# Sabor y Vista

Sitio web oficial del restaurante **Sabor y Vista** — Aguascalientes.

> ¡Tu nuevo lugar favorito te espera! 🍽️☀️

## Sobre el proyecto

Restaurante familiar cerca de la presa, en las afueras de Aguascalientes. Aguachiles, micheladas y sabores que enamoran. Abrimos viernes, sábado y domingo.

## Stack

- HTML + CSS + JS vanilla (sin frameworks)
- Google Fonts: Playfair Display + Poppins
- 100% estático — un solo `index.html`
- Mobile-first responsive
- Logo, banner y menú PDF reales del restaurante en `assets/`

## Deploy

Publicado en Vercel: https://sabor-y-vista.vercel.app
